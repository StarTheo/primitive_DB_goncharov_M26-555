# Primitive DB


Учебная консольная база данных на Python.
Автор: Гончаров Иван Дмитриевич, группа M26-555.



## Текущее состояние


Реализован интерактивный ввод команд:
- help — показать справку;
- exit — завершить программу.

Неизвестная команда выводит сообщение об ошибке.
После обработки команды программа снова запрашивает ввод.
Пробелы в начале и конце команды игнорируются.



## Установка


Нужны uv и Python 3.12 или новее.
uv может автоматически установить подходящий Python.



Установка зависимостей и пакета:

```shell
uv sync
```



## Запуск


Основная команда:

```shell
uv run database
```



Дополнительная команда:

```shell
uv run project
```
